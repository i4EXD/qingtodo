# 隐私与数据说明

适用版本：轻待办 1.3.0。本说明依据随附源码编写。

- 事项标题、备注、完成状态和模板保存于应用私有 SQLite 数据库。
- 颜色主题保存于应用私有 SharedPreferences。
- 应用未声明网络或其他权限，无账号与云同步功能；源码未集成广告或统计 SDK。
- Manifest 设置 `android:allowBackup="false"`，不启用 Android 自动备份。
- 关闭应用和重启手机不会主动删除清单；卸载应用或清除应用数据会删除数据。
- 当前没有导入导出功能。删除操作的撤销窗口是临时恢复功能，不构成数据备份。

下载 APK 时，GitHub 或所用下载服务可能按照其自身政策处理访问数据，该过程与应用本地存储不同。
