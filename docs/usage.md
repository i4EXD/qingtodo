# 使用轻待办

1. 安装 APK 后打开应用，待办清单初始为空。
2. 点击「添加事项」，填写名称和可选备注并保存。
3. 点击事项或左侧圆圈切换完成状态；长按或点右侧菜单编辑。
4. 使用「全部 / 未完成 / 已完成」筛选，查看进度。
5. 在「模板」页创建常用事项，点击「套用」生成新的未完成事项。可反复套用，每条事项的完成状态独立。
6. 添加事项时可选择模板，也可勾选「同时保存为模板」。
7. 删除后及时点击提示条的「撤销」。通常有 10 秒，无障碍设置可延长；后续操作提示可能替换原提示。
8. 在「已完成」筛选中点击「清除已完成」，批量删除后也可在提示期间撤销。
9. 点击右上角调色盘选择颜色，点击「完成」返回；深浅模式跟随系统。

## 常见问题

**模板会自动提醒吗？** 不会，模板需要手动套用。当前没有定时提醒。

**换手机后数据能同步吗？** 当前没有云同步或导入导出，数据只在原手机保存。

**退出应用会丢失清单吗？** 正常退出或重启手机会保留数据；卸载或清除应用数据会删除数据。

**为什么自己构建的 APK 不能覆盖安装？** 必须使用与已安装版本相同的签名密钥。公开仓库不包含原签名密钥；请在独立测试设备安装自建版本，避免卸载导致数据丢失。
